# enterprise-angular-free-ai-web-templates
A curated collection of free enterprise Angular templates for building AI dashboards, SaaS products, admin panels, and web apps.

## Included templates

- `ai-llm-usage-dashboard`
- `ai-prompt-management-panel`
- `ai-rag-knowledge-admin`
- `ai-model-evaluation-board`
- `ai-agent-ops-console`
- `ai-support-copilot-dashboard`
- `ai-sales-assistant-panel`
- `ai-content-studio`
- `ai-fraud-risk-monitoring-ui`
- `ai-human-review-console`

Each folder is a self-contained Angular application with its own `package.json`, `angular.json`, TypeScript configuration, and `src/app` source. Templates use Angular, Bootstrap, Material Symbols, and `@poluru-labs/enterprise-design-system-angular`.

## Run a template

```bash
cd ai-prompt-management-panel
npm install
npm start
```

Replace the project name with any template listed above. Build the chosen template with `npm run build`.
